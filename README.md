# API de Jogos e Promoções

## 📝 Descrição do projeto
Este projeto se trata de um sistema realizado em um trabalho acadêmico e interdisciplinar no ano de 2024.<br>
Consiste na busca de jogos e suas respectivas promoções, que posteriormente são aplicados ao polimorfismo em TypeScript.<br>
Esses dados são armazenados em um catálogo, que possui funções de gerenciamento, como adicionar, remover e pesquisar.<br>
Este catálogo, inclusive, pode ser utilizado tanto com os dados obtidos, como com dados criados pelo próprio usuário.<br>
Os dados são obtidos através da API CheapShark. Ela pode ser encontrada <a href="https://apidocs.cheapshark.com/">aqui</a>.
